# 儿童识字小报生成器

一个利用AI技术为儿童创建带有拼音标签的识字学习小报的应用。

## 功能特点

- 输入主题和标题，自动生成相应场景的识字小报
- 针对不同主题（如超市、医院、公园、动物园、学校等）提供相关的词汇
- 为每个词汇提供拼音和汉字对照
- 使用AI模型生成高质量的卡通插画风格图像
- 支持下载生成的小报图片

## 技术架构

本项目采用纯前端实现：

- **前端**: HTML/CSS/JavaScript 实现用户界面和API调用
- **AI模型**: Nano Banana Pro API 生成图像

## 快速开始

### 运行应用

您可以选择以下任一方式运行应用：

#### 方式一：使用静态服务器
```bash
npm install -g serve
npx serve .
```

应用将在 `http://localhost:5000` 上运行

#### 方式二：直接在浏览器中打开
双击 [index.html](index.html) 文件即可在浏览器中打开应用

### 配置API密钥

1. 访问 [API Key Management Page](https://kie.ai/api-key) 获取您的API密钥
2. 在应用界面中输入API密钥

## 使用方法

1. 在主题/场景框中输入场景名称（如：超市、医院、公园等）
2. 在小报标题框中输入标题（如：《走进超市》《快乐医院》）
3. 点击“生成小报”按钮
4. 等待AI生成图像
5. 生成完成后可以下载图片

## API集成说明

本项目直接从前端调用 Nano Banana Pro API。API密钥通过浏览器本地存储管理，保证安全性。

API调用流程：
1. 使用用户输入的主题和标题生成AI提示词
2. 调用Nano Banana Pro API创建图像生成任务
3. 轮询任务状态直到生成完成
4. 显示生成的图像并提供下载功能

## 扩展性

本项目具有良好的扩展性：

- 可以轻松添加新的主题场景和相关词汇
- 可以调整生成参数以获得不同的图像效果
- 可以集成其他AI图像生成模型

## 注意事项

- 请妥善保管您的API密钥
- 图像生成需要一定时间，请耐心等待
- 生成的图像仅限于教育用途
- 请注意浏览器可能存在的CORS政策限制，可能需要配置允许访问API
